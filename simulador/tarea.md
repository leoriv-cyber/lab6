# Tarea: Mi prompt profesional

## Funcionalidad elegida
Cálculo de promedios de notas finales para estudiantes con estados de aprobación.

## Versión 1: Prompt básico
Haz un programa en Java que calcule el promedio de notas de un estudiante.

## Versión 2
Crea un programa en Java Swing que calcule el promedio de 3 notas. Debe incluir un botón para procesar y validar que los campos no estén vacíos.

## Versión 3: Prompt final
Actúa como un desarrollador Java experimentado. Crea un método estático en Java que reciba un arreglo de números flotantes (notas) y devuelva el promedio. 
Contexto: Es para un sistema de registro académico de educación superior.
Ejemplo: Si las notas son [14.0, 16.0, 18.0], el resultado debe ser 16.0.
Formato: Devuelve únicamente el código Java dentro de un bloque text sin explicaciones adicionales.
Restricción: No uses librerías externas ni utilices JOptionPane dentro de la lógica del método.

## Componentes del prompt final
| Componente | Texto en el prompt |
| :--- | :--- |
| **Rol** | Actúa como un desarrollador Java experimentado. |
| **Instrucción** | Crea un método estático en Java que reciba un arreglo de números flotantes y devuelva el promedio. |
| **Contexto** | Es para un sistema de registro académico de educación superior. |
| **Ejemplo** | Si las notas son [14.0, 16.0, 18.0], el resultado debe ser 16.0. |
| **Formato** | Devuelve únicamente el código Java dentro de un bloque text sin explicaciones adicionales. |

## Evaluación del resultado
| Criterio | ¿Cumple? (Sí / No) |
| :--- | :---: |
| Incluye las restricciones especificadas | Sí |
| Devuelve el código en el formato solicitado | Sí |
| Funciona sin necesidad de librerías externas | Sí |
| Es código limpio y mantenible | Sí |

## Errores que evite
- **Asumir información no proporcionada:** Evité que la IA creara una interfaz visual innecesaria especificando que solo requería el método lógico.
- **Mezclar demasiadas instrucciones:** Separé el rol, el ejemplo y las restricciones en oraciones independientes para que el modelo no ignorara reglas.
